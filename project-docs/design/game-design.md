# 기획 — 성장형 파티빌더 RPG

> 게임 디자인의 owner 문서. 수치는 **시작 제안값(placeholder)** — 시뮬로 측정해 확정. 아키텍처·엔진계약은 [program.md](program.md), UI는 [art.md](art.md), 명령은 [../runbook.md](../runbook.md).

## 1. 비전
랜덤 적에 맞춰 **재화로 파티를 성장시키며(전직·강화·영입·슬롯확장)** 스테이지를 돌파하는 **ATB 자동전투** 싱글 로그라이크. 텍스트 기반으로 충분.
깊이의 출처 = *전투의 운*이 아니라 **(1) 성장 선택의 다축 트레이드오프 (2) 직업 간 카운터 관계망.**

## 2. 디자인 기둥 (모든 결정의 기준)

### 2.1 장르 정체성 (흔들리지 말 것)
- 성장형 파티빌더 RPG. 내가 키운 파티에 애착 생기는 육성 게임.
- 싱글, 런 단위 로그라이크. 지면 런 리셋.
- **성장이 1차, 출전 선발은 부차.** 강제 선별(유닛풀≫슬롯) 중심 아님.
- TFT/오토체스 아님(선별형 아님). 전장 드래프트 아님(고정인원 반가르기 아님).

### 2.2 "정답 맞추기"를 깨는 게 핵심 과제
정답 맞추기 = 입력(몹) 고정 + 선택지 고정 + 결과 결정론 → 최적해 하나, 한 번 찾으면 끝. "성장 없음·고정 시너지·매턴 반복"은 부분 증상일 뿐 — 공식 자체를 깬다. 셋:
- **A. 운(비결정론)** — 단 나쁜 랜덤(빌드 맞았는데 운으로 짐) 금지. 윤활유로만(2.3).
- **B. 자원 경제(제약 아래 선택)** — 최적 알아도 골드부족·비가역·기회비용에 *못 씀*. ← **깊이 1차 출처(4장).**
- **C. 동적 입력(상태 변하는 적·전투)** — 자동전투에선 "더 큰 정답표" 위험 → ATB+마나/쿨의 결정론적 변동성이 안전한 형태(5장).

> 깊이 = 행동 복잡도 아니라 **내 결정이 결과에 계속 영향 주는가**. **결론: 1차 출처=B(성장경제), 전투변수는 보조.**

### 2.3 운(랜덤) 입장
- 나쁜 랜덤(결과 흔들기) 금지. 좋은 랜덤(경직성 푸는 윤활유) 환영.
- 우리 변동성 = 순수 RNG 아니라 **ATB 타이밍 + 마나/쿨 게이팅**(결정론적이나 복잡) → 매치업이 0%/100% 아닌 "23%·67%" 승률 분포.

### 2.4 기각한 방향 (재론 방지)
- 드래프트: 무게중심이 성장→매판 조합싸움 이동 → "다른 게임". 별도 프로젝트로.
- 고정 시너지(일방향 강화): "더 복잡한 정답표"일 뿐 → 카운터의 카운터(6장)로.
- 스킬 가중치 랜덤발동: 나쁜 랜덤 → 우선순위+마나/쿨 게이팅(5.5)으로.
- 출전 슬롯 하드상한: 인위적 벽 대신 **체증 비용**으로.

## 3. 핵심 게임 루프
1. 랜덤 몹 등장 (스탯 + 특수속성).
2. 준비: 골드로 영입(로스터+)/강화(레벨+)/전직(**비가역**)/슬롯확장(**체증**).
3. 출전: 로스터에서 슬롯 수만큼 선발, 적에 맞춰 적응.
4. 자동 전투(ATB, 개입 없음, 라운드 스냅샷 표시).
5. 보상: 승리=골드(향후 유물), 패배=**런 리셋**.
6. 반복. 목표 스테이지 = 시작값 5.

## 4. 성장 경제 (깊이 1차 출처)

### 4.1 골드 사용처 (시작 제안값)
| 항목 | 효과 | 비용 | 트레이드오프 |
|---|---|---|---|
| 영입 | 노비스 로스터 추가 | 4 | 넓히기 |
| 강화 | 레벨+1(스탯↑) | 4 | 깊이기 |
| 전직 | 직업 변경(**비가역**) | 5 | 정체성 |
| 슬롯확장 | 출전+1 | **체증** `5+4*(현재슬롯-3)` | 넓히기(무대) |

시작값: 노비스2·골드5·슬롯3. 클리어 보상 = `4+스테이지`. 슬롯 하드상한 없음(체증이 자율균형), 로스터 소프트상한만(UI보호, 예 10).

### 4.2 다축 트레이드오프 (정답 깨는 엔진)
- 넓히기(영입/슬롯) vs 깊이기(강화) vs 정체성(전직) — 같은 골드 어디에.
- 지금 적 vs 다음 적. 비가역(전직 못 무름). 골드 빠듯 → **무엇을 포기하느냐가 곧 빌드.**
- 슬롯 체증 = 기회비용이 멈춤지점 만듦.
- 다양성(슬롯/영입) ↔ 카운터 대응: 넓은 파티는 속성카운터에 강, 좁은 특화는 효율적이나 엉뚱한 적에 막힘. *상황 따라 다름.*

### 4.3 승리 보상 누적 (향후 — 유물)
기본 누적 = 로스터 성장. 약하면 유물 도입 — *조건부 상호작용*("탱 살면 딜러+20%", "물리면역 적에 마법딜2배"). 전투 밖 유물(골드보너스·전직할인)부터(밸런스 안전). 과하면 "숫자불리기=정답회귀", 양념으로.

## 5. 전투 시스템 — ATB (디자인 규칙)

> 구현 방식·엔진 계약은 [program.md](program.md). 여기는 게임 규칙.

### 5.1 기본 모델
- 완전 자동. 플레이어는 전투 전 빌드만, 전투는 스냅샷으로 봄.
- **틱이 유일한 시계.** 게이지·버프만료·쿨·마나회복 전부 틱 기준.
- **행동력 임계치 1000.** 차면 1회 행동 후 리셋. **속도 = 틱당 게이지 charge량** → 빠른 유닛이 더 *자주* 행동(빈도 차).
- **1 라운드 = 100틱(표시 단위)**, 전투 계산 영향 0. 로그 밀도 취향으로 조정 가능(`ROUND_TICKS`). 1000 택한 이유 = 속도 버프/디버프 세밀 변조 해상도.

### 5.2 버프/디버프 지속 (step5 구현 — effect 시스템)
- 시간형: `expireTick` 기준(라운드 기준 금지 — 가짜 단위). 행동형 `charges`는 미사용(현 4종 전부 시간형).
- 구현=`engine/effects.js`(몹 트레잇과 평행 순수모듈). type=받는뎀/주는뎀 배율·도발·HoT. **스택=refresh**(같은 `(type, 부여자)` 1개·덮어쓰기, 다른 부여자는 별도→곱). 무한 스택 증폭 차단. (구현·엔진계약 → program.md.)

### 5.3 스킬 시스템 (step5 구현 — 직업당 스킬 1개)
- **발동 = 우선순위 톱다운 + 결정론.** 위에서부터 "지금 쓸 수 있는 첫 스킬"(마나≥cost & 쿨 끝), 없으면 평타. 우선순위=`job.skills` 배열 순서(데이터 고정). **플레이어 재배열 UI = step5b(연기).**
- **마나+쿨 게이팅 = 변동성 엔진.** 평타=마나 generator(칠 때마다 충전), 발동스킬=마나 소비. 마나 차는 시점이 ATB 따라 매 전투 미세변동 → 순수 랜덤 없이 변동성(§2.3). 시뮬: L3 파티 S5 9~22/30 분포(조합별 갈림).
- 직업별: 사제 도트힐(HoT) / 전사 방깎(증뎀 디버프)+쎈딜 / 마법사 쎈딜 / 가디언 도발(지속어글+방버프)+평타 보스약뎀감. **노비스=평타만**(전직해야 스킬 — 전직 가치↑).
- 스킬 레벨업 = 성장 축(위력/마나효율/쿨) → step7.

### 5.4 타게팅 규칙
- **딜러** → 적(단일 몹). **힐러** → HP 최저 아군 회복.
- **몹 단일** → 탱 살아있으면 탱(**도발**), 없으면 HP 최저 아군(처치 집중).
- **몹 광역** → 살아있는 전 아군(공격의 일정 비율, 시작값 60%).
- 탱 의미 = 도발로 유리몸 보호 + 고HP로 버팀. (도발=가디언 스킬 발동형 effect, 상시 아님 — 쿨≤지속이라 어글 안 끊김.)

### 5.5 교착 방지
- 최대 틱 상한 초과 → **몹 승(플레이어 패).** 딜이 자가회복·방어 못 뚫는 교착 = 사실상 클리어 불가.

## 6. 직업 / 관계망 (깊이 출처 2)

### 6.1 시작 직업 (L1 시작 제안값)
| 직업 | HP | 공격 | 스피드 | 역할 | 비고 |
|---|---|---|---|---|---|
| 노비스 | 70 | 14 | 7 | 딜러 | 시작직업, 약한 만능 |
| 전사 | 115 | 22 | 9 | 딜러 | 브루저(튼튼·딜낮음) |
| 마법사 | 55 | 32 | 8 | 딜러 | 유리대포(고딜·저HP) |
| 가디언 | 260 | 10 | 5 | 탱커 | 도발(스킬 발동·지속어글), 고HP |
| 사제 | 95 | 6 | 7 | 힐러 | 매 행동 회복(L1 heal 30, 레벨별 증가) |

- 위 = **레벨 1** 값. 레벨별 스탯(hp·공격·heal)은 **직업별 명시 테이블**(공식 아닌 손튜닝, **최대 L5**) — program.md `JOBS.levels{1..5}`. 강화 = level+1, spd는 레벨 불변.
- 노비스 전직 → 전사/마법사/가디언/사제(**비가역**).
- **데미지 = 공격 − 방어(최소1).** phys/magic `타입`은 효과 0이라 **제거됨(step3a)**. RPS 카운터 축 = 스킬의 **근접/원거리**(melee/ranged) + 몹 트레잇(§7.2). (방어무시도 제거 — 2026-05-30.)
- 딜러 사이드그레이드: 전사=튼튼·딜낮음 / 마법사=유리대포·딜높음. 한 직업이 딜·HP 다 높지 않게(지배 방지).
- **마법사 차별점은 현재 고딜/저HP뿐** — 방무시 제거로 niche 약화. 향후 상호작용 동사(예: 방깎)로 차별화 예정.

### 6.2 방향: 직업 = "역할" 아니라 "상호작용 동사" (향후)
직업마다 하는 짓이 다름 + 카운터의 카운터. 동사 예시(확정 아님): 마법사→적 방깎(아군 물리딜↑, **첫 동사 후보**) / 사제→아군 피해감소 / 댄서→공속 둔화·증가 / 어쌔신→힐 차단 / 세이지→버프해제·스킬봉인.

### 6.3 카운터의 카운터 (단일 지배 방지)
동사끼리 물고 물려 최강 조합 수학적으로 불가. 예: 자가회복몹→어쌔신(힐차단)→근데 약함→광역몹이면 먼저 죽음→가디언 보호→…
> **관계망은 출전 슬롯이 넓어야 산다.** 5~6 유닛 있어야 "방깎→폭딜→공속→힐차단" 연쇄 의미. → **무대(슬롯) 먼저, 배우(동사) 나중.**

### 6.4 2차 전직 (향후, 비가역 분기)
노비스→1차→**2차 분기**(예: 전사→로드나이트[단일폭딜] vs 팔라딘[탱+버프]). 비가역 = "내가 키운 캐릭터" 애착 핵심.

## 7. 몬스터 / 적

### 7.1 설계 모델 — 단일 몹 + 속성 다발
- **매 스테이지 한 마리.** 그 한 마리가 능력·스킬 다발 짊어짐. 스테이지 갈수록 다발 개수·강도↑. 적은 데이터로 무한 다양성.
- 재미 = "여러 *마리*" 아니라 "여러 *요구*" 대응.
- **양적 속성**(파워·체력·방어·속도↑): 더 세게 할 뿐 선택 안 바꿈 → 파워크리프. **질적 속성**(근접면역·자가회복·반사·광역·근접회피): 특정 답 요구 → RPS 연료. **규칙: 속성 풀 중심 = 질적, 양적은 양념.**

### 7.2 특수 속성 (RPS 카운터 — step3b 규칙엔진으로 구현)
> 카운터 축 = phys/magic 아님(step3a에서 type 제거). **스킬의 근접/원거리(melee/ranged)**. 트레잇 = 규칙(trigger/cond/op), 구현·어휘는 [program.md](program.md). 표는 §7.2 로스터 = `TRAITS` 정의됨, 라이브 부착은 근접회피만(나머지는 step3b 후속).

| 속성 | 효과(시작값) | 카운터 |
|---|---|---|
| 근접회피 ✅라이브 | 근접 받는뎀 −30%(확정) | 원거리 딜러(마법사) |
| 근접면역 | 근접 0 | 원거리 딜러 |
| 원거리저항 | 원거리 절반 | 근접 딜러 |
| 자가회복 | 매 턴 회복 | 폭딜/(향후)힐차단 |
| 데미지반사 | 준 딜 %반사 | 탱/저딜 |
| 광역공격 ✅엔진네이티브 | 전체(공격 60%) | 탱·힐 |

- 회피는 §2.3 "나쁜 랜덤 금지"대로 %확률 아닌 **확정 −30%**(결정론). 속성 개수 점증(초반 0~1, 후반 2). **상호배제: 모든 딜 타입 동시 봉쇄(근접면역+원거리저항) 금지** — 클리어 불가 방지.

### 7.3 향후 — 부드러운 카운터
속성을 on/off 아닌 **정도(degree)**로("물리 70% 감소"). 몹에 상호작용 타입(버프/회복/속도형) 부여.

## 8. 밸런싱 방법론
- **눈대중 금지 — 시뮬로 측정해 확정.** (시뮬 구현 → [program.md](program.md))
- 방식: 전수 조합 승률(중복허용 파티 전부 × 스테이지/속성 × trial).
- **검증 기준 3:** ①모든 스테이지/속성에 클리어 가능(50%+) 조합 **존재** ②**단일 지배 조합 없음** ③속성별 최적 조합이 **갈림**(RPS 작동).
- ATB라 속도가 행동빈도로 증폭 → **speed 포함 측정.**

### 8.1 밸런싱 함정 (피할 것)
1. **방어 스케일링이 딜 죽임** → 방어 낮게 고정, "방어 트레이드오프"는 질적 속성(근접면역/원거리저항)으로.
2. **고정 파티 vs 스케일링 몹 = 진행 불가** → 몹 스케일 눕히거나 성장이 따라가게.
3. **한 직업이 딜·체력 다 높으면 지배** → 딜러 사이드그레이드.
4. **광역 과하면 전멸** → 비율 낮춰 탱·힐로 버틸 여지(시작값 60%).
