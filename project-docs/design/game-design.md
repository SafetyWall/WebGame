# 기획 — 성장형 파티빌더 RPG

> 게임 디자인의 owner 문서. 수치는 **시작 제안값(placeholder)** — 시뮬로 측정해 확정. 아키텍처·엔진계약은 [program.md](program.md), UI는 [art.md](art.md), 명령은 [../runbook.md](../runbook.md).

## 1. 비전
랜덤 적에 맞춰 **재화로 파티를 성장시키며(전직·강화·영입·슬롯확장)** 스테이지를 돌파하는 **ATB 자동전투** 싱글 로그라이크. 텍스트 기반으로 충분.
깊이의 출처 = *전투의 운*이 아니라 **(1) 성장 선택의 다축 트레이드오프 (2) 직업 간 카운터 관계망.**

## 2. 디자인 기둥 (모든 결정의 기준)

### 2.1 장르 정체성 (흔들리지 말 것)
- 성장형 파티빌더 RPG. 내가 키운 파티에 애착 생기는 육성 게임.
- 싱글, 런 단위 로그라이크. 지면 런 리셋.
- **성장이 1차, 출전 선발은 부차.** 강제 선별(유닛풀≫슬롯) 중심 아님.
- TFT/오토체스 아님(선별형 아님). 전장 드래프트 아님(고정인원 반가르기 아님).

### 2.2 "정답 맞추기"를 깨는 게 핵심 과제
정답 맞추기 = 입력(몹) 고정 + 선택지 고정 + 결과 결정론 → 최적해 하나, 한 번 찾으면 끝. "성장 없음·고정 시너지·매턴 반복"은 부분 증상일 뿐 — 공식 자체를 깬다. 셋:
- **A. 운(비결정론)** — 단 나쁜 랜덤(빌드 맞았는데 운으로 짐) 금지. 윤활유로만(2.3).
- **B. 자원 경제(제약 아래 선택)** — 최적 알아도 골드부족·비가역·기회비용에 *못 씀*. ← **깊이 1차 출처(4장).**
- **C. 동적 입력(상태 변하는 적·전투)** — 자동전투에선 "더 큰 정답표" 위험 → ATB+마나/쿨의 결정론적 변동성이 안전한 형태(5장).

> 깊이 = 행동 복잡도 아니라 **내 결정이 결과에 계속 영향 주는가**. **결론: 1차 출처=B(성장경제), 전투변수는 보조.**

### 2.3 운(랜덤) 입장
- 나쁜 랜덤(결과 흔들기) 금지. 좋은 랜덤(경직성 푸는 윤활유) 환영.
- 우리 변동성 = 순수 RNG 아니라 **ATB 타이밍 + 마나/쿨 게이팅**(결정론적이나 복잡) → 매치업이 0%/100% 아닌 "23%·67%" 승률 분포.

### 2.4 기각한 방향 (재론 방지)
- 드래프트: 무게중심이 성장→매판 조합싸움 이동 → "다른 게임". 별도 프로젝트로.
- 고정 시너지(일방향 강화): "더 복잡한 정답표"일 뿐 → 카운터의 카운터(6장)로.
- 스킬 가중치 랜덤발동: 나쁜 랜덤 → 우선순위+마나/쿨 게이팅(5.5)으로.
- 출전 슬롯 하드상한: 인위적 벽 대신 **체증 비용**으로.

## 3. 핵심 게임 루프
1. 랜덤 몹 등장 (스탯 + 특수속성).
2. 준비: 골드로 영입(로스터+)/강화(레벨+)/전직(**비가역**)/슬롯확장(**체증**).
3. 출전: 로스터에서 슬롯 수만큼 선발, 적에 맞춰 적응.
4. 자동 전투(ATB, 개입 없음, 라운드 스냅샷 표시).
5. 보상: 승리=골드(향후 유물), 패배=**런 리셋**.
6. 반복. 목표 스테이지 = **50**(장기 100, MAX_STAGE만 변경). 절차생성 곡선.

## 4. 성장 경제 (깊이 1차 출처)

### 4.1 골드 사용처 (시작 제안값)
| 항목 | 효과 | 비용 | 트레이드오프 |
|---|---|---|---|
| 영입 | 노비스 로스터 추가 | 4 | 넓히기 |
| 강화 | 레벨+1(스탯↑, ~L10) | 8 | 깊이기 (**노비스는 강화 불가 — 전직이 그 자리**) |
| 전직 | 직업 변경(**비가역**) **+ 레벨+1 + 기본 스킬1 학습** | 10 | 정체성 |
| 스킬 학습 | 액티브 1개 보유(전직 기본 외 추가) | 6 | 깊이기(스킬 폭) |
| 스킬 레벨업 | 스킬 위력↑(L5=L1 2배, 직선) | 4 | 깊이기(스킬 강화) |
| 슬롯확장 | 출전+1 | **체증** `5+4*(현재슬롯-3)` | 넓히기(무대) |

시작값: 노비스2·골드20·슬롯3. 클리어 보상 = `10+2*스테이지`. 슬롯 하드상한 없음(체증이 자율균형). **경제 목표: 풀투자=클리어, 무투자=즉사.** **현 측정(econ-sim, MAX_STAGE 50): 풀투자도 중앙 S28 전멸·클리어 0/30 — `levelCurve` 지수 곡선이 50스테 못 버팀 → 곡선 완화 미해결**(TODOS). 캐릭레벨업(8) > 스킬레벨업(4) 비용.
- **전직 = 레벨업.** 노비스는 전직 레벨(L1)에서 강화 대신 **전직만** — 전직 시 레벨 +1 + 기본 액티브 1개 학습. 나머지 액티브 3개는 골드로 학습. (2차 전직은 레벨 10에서 — 향후.)

### 4.2 다축 트레이드오프 (정답 깨는 엔진)
- 넓히기(영입/슬롯) vs 깊이기(강화) vs 정체성(전직) — 같은 골드 어디에.
- 지금 적 vs 다음 적. 비가역(전직 못 무름). 골드 빠듯 → **무엇을 포기하느냐가 곧 빌드.**
- 슬롯 체증 = 기회비용이 멈춤지점 만듦.
- 다양성(슬롯/영입) ↔ 카운터 대응: 넓은 파티는 속성카운터에 강, 좁은 특화는 효율적이나 엉뚱한 적에 막힘. *상황 따라 다름.*

### 4.3 승리 보상 누적 (향후 — 유물)
기본 누적 = 로스터 성장. 약하면 유물 도입 — *조건부 상호작용*("탱 살면 딜러+20%", "물리면역 적에 마법딜2배"). 전투 밖 유물(골드보너스·전직할인)부터(밸런스 안전). 과하면 "숫자불리기=정답회귀", 양념으로.

## 5. 전투 시스템 — ATB (디자인 규칙)

> 구현 방식·엔진 계약은 [program.md](program.md). 여기는 게임 규칙.

### 5.1 기본 모델
- 완전 자동. 플레이어는 전투 전 빌드만, 전투는 스냅샷으로 봄.
- **틱이 유일한 시계.** 게이지·버프만료·쿨·마나회복 전부 틱 기준. **100틱 = 1초**(`TICKS_PER_SEC`) — 내부는 틱, **UI는 초 표시**(쿨·지속·시간; "틱"이 일반 유저에 비직관적이라).
- **행동력 임계치 10000.** 차면 1회 행동 후 리셋(carry). **속도 = 틱당 게이지 charge량(100-스케일)** → **속도 100 = 100틱마다 행동 = 1초/턴**. 속도 S → S/100 행동/초(예 90 → 1.111초/턴). 쿨타임은 속도 무관 실시간(절대 틱).
- **1 라운드 = 100틱 = 1초(표시 단위)**, 전투 계산 영향 0(`ROUND_TICKS`). 임계치 10000 = 속도 100-스케일에서 1초/턴 + 속도 버프/디버프 세밀 변조 해상도.

### 5.2 버프/디버프 지속 (구현 — effect 시스템)
- 시간형: `expireTick` 기준(라운드 기준 금지). 행동형 `charges` 미사용.
- 구현=`engine/effects.js`(몹 트레잇과 평행 순수모듈). type 10종: 배율(받는뎀/주는뎀/속도)·플래그(도발/스턴/intercept)·지속(HoT/DoT)·반사·표식. **스택=refresh**(같은 `(type, 부여자)` 덮어쓰기, 다른 부여자 별도→곱). **스킬 레벨업 시 effect 위력도 스케일**(1.0 기준 편차×배율, 또는 직접×배율). (구현·엔진계약 → program.md.)

### 5.3 스킬 시스템 (구현 완료 — 직업당 평타 + 액티브 4)
- **직업당 = 평타 + 액티브 4.** 전직 시 액티브 1개 기본 학습, 나머지 3개는 골드로 학습(§4.1). 스킬 Lv1~5(레벨업 = L5에서 위력 2배, 직선 `1+0.25(lv-1)`). **노비스=평타만**(전직해야 스킬).
- **발동 = 우선순위 톱다운 + 결정론.** 위에서부터 "지금 쓸 수 있는 첫 스킬"(마나≥cost & 쿨 끝), 없으면 평타. 플레이어 재배열(roster `skillOrder`, ▲▼·무료). 평타를 1순위로 올리면 발동스킬 안 씀(의도).
- **마나+쿨 게이팅 = 변동성 엔진.** 평타=마나 generator, 발동스킬=마나 소비. 마나 차는 시점이 ATB 따라 미세변동 → 순수 랜덤 없이 변동성(§2.3). **마나 상한=직업별**(기본100·마법사/사제 120, 레벨 불변=전직으로만).
- **스킬 메커닉(구현 9종)**: 속도(가감속)·스턴(게이지 정지)·파티 전체 타겟·반사·intercept(대신받기)·mark(피격 추가뎀)·DoT(지속뎀)·멀티히트(N타)·방어무시. 직업 키트 = program.md `JOBS`/`SKILLS`. 예: 마법사 파이어볼·마력집중·빙결·라이트닝 / 가디언 무기파괴·방벽·가시방패·수호 / 도적 출혈·속도·더블어택·방어무시 / 궁수 조준사격·연사·방어구관통·속박사격.

### 5.4 타게팅 규칙 (위협도 스코어)
- **딜러** → 적(단일 몹). **힐러** → HP 최저 아군 회복.
- **몹 단일** → **위협도 스코어 최고 생존자**(factor 가중합, 결정론·RNG 0). 디폴트 = **위치 지배 → 앞열(파티 순서 맨앞)**. 플레이어가 출전 순서로 통제(탱 앞·마법사 뒤). 도발 = 그 유닛 위협도 폭증(override).
- **몹 광역** → 살아있는 전 아군(공격의 일정 비율, 시작값 60%).
- **다양성 = 몹 트레잇이 weight 변조**(저체력추적 = 슬롯 무관 마법사 직격). 위치 기반 변주(후열관통 등)는 자유 재배열로 trivial → 보류, **스탯 기반만**. 카운터 = 수호(가디언 intercept)·도발·성장.
- 탱 의미 = 앞열 소킹 + 수호로 약자 보호 + 고HP. (도발 스킬은 가디언 기본 키트서 제외 = 2차전직용 메커니즘으로 유지.)

### 5.5 교착 방지
- 최대 틱 상한 초과 → **몹 승(플레이어 패).** 딜이 자가회복·방어 못 뚫는 교착 = 사실상 클리어 불가.

## 6. 직업 / 관계망 (깊이 출처 2)

### 6.1 직업 (L1 제안값 — 전체 테이블·스킬 = program.md)
| 직업 | HP | 공격 | 스피드 | **시그니처** | 정체성 |
|---|---|---|---|---|---|
| 노비스 | 70 | 14 | 100 | — | 시작직업, 평타만(전직 전) |
| 전사 | 115 | 22 | 120 | **받는뎀↑(약화·팀증폭)** | 튼튼 프론트·약보조·개인DPS 최저 — 갑옷부수기·강타·분쇄(스턴)·방벽(자기방어) |
| 마법사 | 55 | 32 | 90* | **표식** | 원거리 딜 — 파이어볼(버스트)·마력집중·라이트닝(표식)·빙결(딜) |
| 사제 | 95 | 24 | 100 | **파티 버프(블레싱·민첩성증가)** | 약공격 가능 버퍼(라그 복사) — 치유·파티힐·블레싱(주는뎀↑)·민첩성증가(속도↑) + 평타딜(전사<) |
| 도적 | 90 | 26 | 150 | **출혈(DoT)+자가속** | 속도 근딜 — 출혈·속도·더블어택·방어무시 |
| 궁수 | 75 | 28 | 120 | **감속** | 지속 원딜·약보조 — 조준사격·연사·방어구관통·속박(감속) |
> 스피드 = **100-스케일**(100 = 1초/턴). 전사120·도적 150(빠름)~마법사 90(느림). spd·mana·def 레벨 불변. *마법사 spd90 = 느린버스트 실험치, 베이스 평범 원딜로 환원 예정(TODO).
> **가디언 = 베이스 제외 → 전사 2차전직(미래).** 잔여 스킬(무기파괴=주는뎀↓·가시방패=반사·수호=intercept·강화)은 2차전직 보관(JOB 정의·SKILLS 유지).

- 레벨별 스탯 = **직업별 명시 테이블 L1~10**(손튜닝, program.md `JOBS.levels{1..10}`). 강화 = level+1(~10), spd·mana 레벨 불변.
- 노비스 전직 → **5직업**(전사/마법사/사제/도적/궁수, **비가역**). 가디언은 전사 2차전직(미래). L1에서 강제, 전직 시 레벨+1 + 기본 액티브 1개 학습(§4.1).
- **초반 강제 직업 0 (설계 핵심).** 3슬롯 초반에 전사·힐러 필수면 안 됨. 각 직업 = **유용(있으면 유리) + 필수 아님 + 카운터 가능**(시그니처를 몹 트레잇이 무력화: 힐봉쇄→사제·디버프면역→전사 받는뎀↑/마법사 표식/궁수 감속·지속면역→도적 출혈). = 카운터의 카운터(§6.3)·단일 지배 없음(§8). **날카로운 정체성·극단 스탯은 2차전직**(예: 마법사 진짜 글래스캐논, 가디언 하드탱). 검증: 무탱·무힐 3조합도 초반 클리어(econ-sim).
- **데미지 = 공격 × K/(방어+K) (% 경감, 최소1).** def=0→항등, def=K→50% 경감. **스케일 불변**(레벨·스테이지 무관 동일 %)이라 옛 플랫식의 "딜 죽임" 함정(§8.1.1) 회피. phys/magic 타입 제거(step3a). RPS 축 = 스킬 근접/원거리 + 몹 트레잇(§7.2) + **방어무시(도적)·관통(몹)** = 고방 카운터.
- **플레이어 def = 직업 메타 상수**(탱 정체성 레버 — 가디언↑/전사 중/딜러 0). % 경감이라 레벨 성장 불필요. 몹 def도 같은 식. 수치=placeholder(econ-sim).
- 사이드그레이드(지배 방지): 전사=튼튼/개인딜 최저/팀증폭, 마법사=원거리 버스트/저HP, 도적=고속 근딜, 궁수=지속 원딜/약보조. HP·DPS 격차는 **좁게**(정체성 ↔ 강제회피 균형). 정체성 = **시그니처 1개씩**(효과 직업 독점)으로 차별.

### 6.2 직업 = "역할" 아니라 "상호작용 동사" (대부분 구현)
직업마다 하는 짓이 다름 + 카운터의 카운터. **시그니처 동사(직업 독점):** 전사→받는뎀↑(약화·팀증폭) / 마법사→표식(피격증뎀) / 사제→파티 버프(블레싱=주는뎀↑·민첩성증가=속도↑) + 약공격 / 도적→출혈(DoT)·자가속 / 궁수→감속. (가디언→주는뎀↓·반사·intercept = 2차전직 보관.) 향후 동사: 방깎·힐차단·버프해제 등(brainstorm).

### 6.3 카운터의 카운터 (단일 지배 방지)
동사끼리 물고 물려 최강 조합 수학적으로 불가. 예: 자가회복몹→어쌔신(힐차단)→근데 약함→광역몹이면 먼저 죽음→가디언 보호→…
> **관계망은 출전 슬롯이 넓어야 산다.** 5~6 유닛 있어야 "방깎→폭딜→공속→힐차단" 연쇄 의미. → **무대(슬롯) 먼저, 배우(동사) 나중.**

### 6.4 2차 전직 (향후, 비가역 분기)
노비스→1차→**2차 분기**(예: 전사→로드나이트[단일폭딜] vs 팔라딘[탱+버프]). 비가역 = "내가 키운 캐릭터" 애착 핵심.

## 7. 몬스터 / 적

### 7.1 설계 모델 — 단일 몹 + 속성 다발
- **매 스테이지 한 마리.** 그 한 마리가 능력·스킬 다발 짊어짐. 스테이지 갈수록 다발 개수·강도↑. 적은 데이터로 무한 다양성.
- 재미 = "여러 *마리*" 아니라 "여러 *요구*" 대응.
- **양적 속성**(파워·체력·방어·속도↑): 더 세게 할 뿐 선택 안 바꿈 → 파워크리프. **질적 속성**(근접면역·자가회복·반사·광역·근접회피): 특정 답 요구 → RPS 연료. **규칙: 속성 풀 중심 = 질적, 양적은 양념.**
- **일반 몹 vs 보스 분리(구현됨).** *일반 몹* = 고정 특성 없음 — 스테이지 슬롯 랜덤 특성만 짊어짐(슬라임·가시거북). *보스* = **고정 능력**(광역 등 intrinsic)을 항상 보유 + 스테이지 슬롯 외 **추가 트레잇 슬롯**(`bonus`). 광역 같은 강한 능력을 일반 몹이 추가로 갖는 건 과함 → 그런 몹은 보스로. 광역은 엔진 네이티브 능력(트레잇 아님, 보스 전용)이지만 UI엔 트레잇과 함께 `[광역, …]`로 표기. **모드 2종**(`mob.aoeMode`): `uniform`=전원 `atk×aoeRatio`(기본) / `splash`=주타깃 풀뎀(×1.0)+그외 `atk×aoeRatio`. **보스 스테이지 배치는 미정**(정의만 — 오우거·드래곤).

### 7.2 특수 속성 (트레잇 — RPS 카운터)
> **등급 = 플레이어가 강요받는 적응의 크기**(순수 수치 아님). 일반=스탯 너지(적응 불필요) → 영웅=빌드 왜곡. **자동전투라 모든 트레잇은 빌드 단계 결정으로 풀려야 함**(인게임 타이밍/타겟 순발력 요구 = 무효). 3계열: **규칙형**(데미지 변환 trigger/op)·**타겟팅형**(몹 타겟 weight)·**스탯형**(생성 시 base 스탯 ×mult). 구현·어휘 [program.md](program.md).
> **페어 패턴:** 사거리·힐·DoT·디버프·광역 = **부분(희귀)/완전(영웅)** 쌍 → 등급 자(尺) 일관.

**슬롯 규칙:** 10스테이지마다 1슬롯 추가, 순서 = 일반/희귀/일반/영웅/희귀 누적(`stages.SLOT_SEQ`). ~10:일반1 / ~20:+희귀 / ~30:+일반 / ~40:+영웅 / ~50:+희귀.

**1차 (라이브 — 기존 엔진):**
| 등급 | 속성 | 효과 | 카운터하는 빌드 |
|---|---|---|---|
| 일반 | 맹공/철갑/강골 | 공·방·체 +20% | (스탯 너지) |

| 희귀 | 자가회복 | 매 턴 +20 | 저DPS |

- 광역(부분/스플래시)은 §7.1 **네이티브 모드**(트레잇화 안 함). 구현·메타 어휘 → [program.md](program.md).

- **상호배제**(`encounter.conflicts`, `defends` 메타): 한 범위 완전봉쇄(면역) + 다른 범위 방어 동시 금지 → 전딜봉쇄(클리어 불가) 차단. 같은범위·부분+부분(회피+저항) 허용. → S40+ 영웅 면역이 일반(회피+저항) 둘과 충돌 시 ~7% 슬롯 스킵(의도된 안전).

### 7.3 향후 — 부드러운 카운터
속성을 on/off 아닌 **정도(degree)**로("물리 70% 감소"). 몹에 상호작용 타입(버프/회복/속도형) 부여.

## 8. 밸런싱 방법론
- **눈대중 금지 — 시뮬로 측정해 확정.** (시뮬 구현 → [program.md](program.md))
- 방식: 전수 조합 승률(중복허용 파티 전부 × 스테이지/속성 × trial).
- **검증 기준 3:** ①모든 스테이지/속성에 클리어 가능(50%+) 조합 **존재** ②**단일 지배 조합 없음** ③속성별 최적 조합이 **갈림**(RPS 작동).
- ATB라 속도가 행동빈도로 증폭 → **speed 포함 측정.**

### 8.1 밸런싱 함정 (피할 것)
1. **방어 스케일링이 딜 죽임 — 플랫식(`공−방`) 한정.** % 경감식 `atk×K/(def+K)`은 스케일 불변이라 이 함정 회피 → 플레이어 def 복귀(탱 정체성 레버, §6.1). 옛 플랫식 폐기. 질적 속성(근접면역/원거리저항)도 병행.
2. **고정 파티 vs 스케일링 몹 = 진행 불가** → 몹 스케일 눕히거나 성장이 따라가게.
3. **한 직업이 딜·체력 다 높으면 지배** → 딜러 사이드그레이드.
4. **광역 과하면 전멸** → 비율 낮춰 탱·힐로 버틸 여지(시작값 60%).
