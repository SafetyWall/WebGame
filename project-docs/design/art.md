# 아트 / UI

> UI·표현의 owner. 전투 표시 규칙(라운드 단위 등)은 [game-design.md](game-design.md) §5.1, 렌더 구현은 [program.md](program.md) `render.js`.

## 표현 철학
- **텍스트 RPG 범위로 충분.** 화려한 그래픽 불필요.
- 전투는 플레이어 개입 없이 진행 → **라운드 스냅샷 로그**로 결과를 끊어 보여줌.

## 현재 화면 (베이스)
- `index.html` — 단일 페이지, 다크 모노스페이스 테마, `#app`에 렌더 mount.
- 색: 제목 `#fc6` / 아군 HP `.hp` `#6c6` / 몹 `.mob` `#e88` / 로그 `.log` `#9af`, 배경 `#111`.
- `render.js`: 결과 헤더(`승리/패배 (N틱)`) + 라운드별 `<section>`(파티 HP 텍스트 `이름 hp/maxHp` | 몹 HP + 행동 로그 줄). 세로 나열.

## 향후 비주얼 방향 (미구현)
- HP 바 시각화, 라운드 단계/타임라인 표시.
- 직업·속성 텍스트 심볼/색으로 타입·카운터 힌트.
- 준비 단계 UI(영입/강화/전직/슬롯) — 경제 단계(§9 step4)와 함께.
- 모바일 가독.
