# 아트 / UI

> UI·표현의 owner. 전투 표시 규칙(라운드 단위 등)은 [game-design.md](game-design.md) §5.1, 렌더 구현은 [program.md](program.md) `render.js`.

## 표현 철학
- **텍스트 RPG 범위로 충분.** 화려한 그래픽 불필요.
- 전투는 플레이어 개입 없이 진행 → **라운드 스냅샷 로그**로 결과를 끊어 보여줌.

## 현재 화면 (플레이어블 코어 루프)
- `index.html` — 단일 페이지, 다크 모노스페이스 테마, `#app`에 렌더 mount. 버튼·로스터·미리보기 스타일 추가.
- 색: 제목 `#fc6` / 아군 HP `.hp` `#6c6` / 몹 `.mob` `#e88` / 트레잇 `.traits` `#fc6` / 로그 `.log` `#9af`, 배경 `#111`.
- `ui/game.js` `renderGame(state)` 2국면: **준비**(스테이지/골드/슬롯 헤더 + 다가올 몹 미리보기 + 로스터[강화·출전 버튼] + 영입·전투 버튼) / **결과**(승리·패배·클리어 배너 + 보상 + `renderBattle` 로그 + 다음/다시시작 버튼). 버튼 = `data-action`, `main.js` 이벤트 위임.
- `render.js`: 전투 로그 렌더(결과 헤더 + 라운드별 `<section>`) — game.js 결과 국면이 재사용.

## 향후 비주얼 방향 (미구현)
- HP 바 시각화, 라운드 단계/타임라인 표시.
- 직업·속성 텍스트 심볼/색으로 타입·카운터 힌트.
- 준비 단계 UI — 영입/강화는 **구현됨**(prep 국면). 전직/슬롯확장 UI는 다음.
- HP 바 시각화, 결과 화면 이중 헤더(배너+renderBattle) 정리, 풀파티 시 출전버튼 비활성 피드백.
- 모바일 가독.
