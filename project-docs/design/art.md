# 아트 / UI

> UI·표현의 owner. 전투 표시 규칙(라운드 단위 등)은 [game-design.md](game-design.md) §5.1, 렌더 구현은 [program.md](program.md) `render.js`.

## 표현 철학
- **텍스트 RPG 범위로 충분.** 화려한 그래픽 불필요.
- 전투는 플레이어 개입 없이 진행 → **라운드 스냅샷 로그**로 결과를 끊어 보여줌.

## 현재 화면
- `index.html` — 단일 페이지, 다크 모노스페이스 테마, `#app`에 렌더 mount. 버튼·로스터·미리보기 스타일.
- 색: 제목 `#fc6` / 아군 HP `.hp` `#6c6` / 몹 `.mob` `#e88` / 트레잇 `.traits` `#fc6` / 로그 `.log` `#9af`, 배경 `#111`.
- `ui/game.js` `renderGame(state)` 2국면: **준비**(스테이지/골드/슬롯 헤더 + 다가올 몹 미리보기 + 로스터[강화·전직·출전 버튼] + 영입·슬롯확장·전투 버튼, 풀파티 시 출전 disabled) / **결과**(승리·패배·클리어 배너 + 보상 + `renderRounds` 로그 + 다음/다시시작 버튼). 버튼 = `data-action`, `main.js` 이벤트 위임.
- `render.js`: `renderRounds`(라운드별 `<section>`) + 하위호환 `renderBattle`. game.js 결과 국면이 재사용.
- **스킬(step5)은 전투 로그에 텍스트로 자동 노출**(공격·회복·지속회복 라인). 마나/쿨/effect **전용 표시(바·아이콘)는 미구현** — 엔진만 보유, UI 표면화는 향후.

## 향후 비주얼 방향 (미구현)
- HP 바 시각화, 라운드 단계/타임라인 표시.
- 마나 바·쿨다운·버프/디버프(effect) 아이콘 표시 — 현재 전투 로그 텍스트로만 드러남.
- 직업·속성 텍스트 심볼/색으로 타입·카운터 힌트.
- 스킬 우선순위 재배열 UI (step5b).
- 모바일 가독.
